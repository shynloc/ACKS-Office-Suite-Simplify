# Markdown 写法与呈现

Word 与 PDF 的正文都用 Markdown（CommonMark + 表格、删除线）。单个换行会保留为换行。
下表的样式都随主题变化（见 [design-system.md](design-system.md)）。

| 写法 | 呈现 |
|---|---|
| `# 标题` / `##` / `###` 及以下 | 一至三级标题；slate 自动编号；folio 的一级标题是章节页 |
| `# 标题 {label="生意 · THE BUSINESS"}` | folio 章节页的标签；「 · 」前的部分用在页眉和封面目录 |
| `**粗体**`、`*斜体*`、`~~删除~~` | 对应格式 |
| `` `代码` `` | 等宽字体、强调色 |
| `[文字](https://…)` | 可点击链接 |
| `- 项目`（可嵌套）/ `1. 项目` | 项目符号 / 编号列表，每个列表各自从起始号开始 |
| `- [ ] 待办` / `- [x] 完成` | ☐ / ☑（PDF 为 □ / ■） |
| 表格（`\|` 分隔） | 主题化表格；数字列或按 `---:` 右对齐；首列以「合计 / 总计 / Total」开头的行按合计行处理 |
| 表格前后紧挨一段 `表：标题`（或 `Table: 标题`） | 表题，自动编号「表 1」 |
| `> 引用` | 引文；folio 中紧跟一级标题的引用是该章导语 |
| `> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` | 提示块，标签为「说明 / 提示 / 重要 / 警告 / 注意」 |
| 代码块（三个反引号） | 浅底代码框，长行自动折行 |
| `---` | 分隔线 |
| `![说明](图片.png)` | 图片（超过版心宽度时等比缩小）+ 自动编号的图题 |

- 开头可以写 front matter（`title`、`subtitle`、`kicker`、`author`、`date`、`version`、`issue`、`lede` 等），
  见 [commands.md](commands.md)。
- 图片的相对路径以正文文件所在目录为准（用 `--content-file` 时）；找不到图片时用文字占位，
  并给出 `IMAGE_NOT_FOUND` 提醒。
- 不支持原始 HTML（会按普通文字显示）。
- 文档标题用 `--title` 或 front matter 传入，不要在正文里再写一遍同样的 `#` 标题。
