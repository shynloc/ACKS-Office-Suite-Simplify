# Markdown 写法与呈现

Word 与 PDF 的正文都用 Markdown（CommonMark + 表格、删除线）。单个换行会保留为换行。

| 写法 | Word（acks 主题） | Word（default 主题） | PDF |
|---|---|---|---|
| `# 标题` / `##` / `###` 及以下 | 章节标题 / 小标题 / 标签 | 标题 1 / 2 / 3 | 三级标题样式 |
| `**粗体**`、`*斜体*`、`~~删除~~` | 对应格式 | 对应格式 | 对应格式 |
| `` `代码` `` | 等宽、强调色 | Consolas | 深红色 |
| `[文字](https://…)` | 可点击链接 | 可点击链接 | 可点击链接 |
| `- 项目`（可嵌套） | 品牌符号列表 | 项目符号 | • |
| `1. 项目` | 01、02 编号 | 自动编号，每个列表各自从起始号开始 | 1. 2. |
| `- [ ] 待办` / `- [x] 完成` | ☐ / ☑ | ☐ / ☑ | □ / ■ |
| 表格（`\|` 分隔） | 规范表格，数字列右对齐 | 网格表格，数字列右对齐 | 网格表格，按 `---:` 右对齐 |
| `> 引用` | 引文样式 | Quote 样式 | 左侧竖线 |
| `> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` | 提示块 / 重点块 | 强调引文 | 带标签的引文 |
| 代码块（三个反引号） | 代码框 | 灰底等宽 | 灰底，长行自动折行 |
| `---` | 分隔线 | 分隔线 | 分隔线 |
| `![说明](图片.png)` | 图片（超过版心宽度时等比缩小）+ 图注 | 同左 | 同左 |

- 图片的相对路径以正文文件所在目录为准（用 `--content-file` 时）；找不到图片时用文字占位，
  并给出 `IMAGE_NOT_FOUND` 提醒。
- 不支持原始 HTML（会按普通文字显示）。
- 文档标题用 `--title` 传入，不要在正文里再写一遍同样的 `#` 标题。
